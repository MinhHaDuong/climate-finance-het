# JETP research briefs

For JETP source searches, use the [scout brief](../../docs/jetp-scout-brief.md)
before launching a scout or a new research round. This applies to solo work
as well as delegated searches; it does not itself authorize delegation.

- Name the unresolved project identity and the document needed to resolve it.
  Prefer contract numbers, village schedules, original project fiches, operation
  identifiers and official catalogues over another broad keyword search.
- State the identity acceptance criteria before searching. A shared place,
  technology or budget is a lead; it cannot alone join two project identities.
- Bound each assignment by calls or time and an explicit stop condition. A
  failed route means unavailable through that route on that date, not absent.
- Return primary-source locators, contrary evidence and the exact remaining
  gap. Separate identity, financing status, physical progress and JETP attribution.
  Conditional budgets, approvals and payment orders do not establish settlement.
- The parent checks the original source and adjudicates proposed ledger changes;
  a solo researcher performs a separate verification pass. Scouts return findings
  without promoting coverage or financial/physical events themselves.
- Start another round only with a named new document, route or discriminating
  question. Record the previous round's yield and why the next can add evidence.
  Exhausting a search budget does not establish saturation.

Use existing authorization for retrieval and publication. These instructions
add no authorization to send institutional requests or publish data.
