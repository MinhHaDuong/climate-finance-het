# Recovering OA links (note for the Zenodo package README, ed04 kit)

Displaced from data-paper.qmd §3 by cut-plan v2 item W7 (ticket-ref 0274).
Destination: a "Recovering OA links" section in the Zenodo package README
when the ed04 kit is rebuilt.

The corpus does not include a dedicated Open Access or fulltext URL column.
Users can recover OA links via the OpenAlex API using the `source_id` field,
or construct ISTEX fulltext URLs from the ISTEX identifiers in the source
catalogs under `data/inputs/`.
