# R1-19 — organization of climate_finance_corpus.csv

Response-letter bullet (feeds ticket 0283; letter-voice: first person
singular).

> **R1-19** (CSV organization). I kept the file layout. The file is a
> standard rectangular CSV (26 columns, no duplicate rows) that loads
> directly into pandas or R, and its columns already follow four logical
> groups in a fixed order: record identity (`source`, `source_id`, `doi`),
> bibliographic metadata (title through affiliations), provenance flags
> (the `from_*` columns and provenance fields), and curation metadata (the
> quality flags and protection fields). Reordering or reshaping the columns
> would change a published Zenodo artifact and break every downstream
> consumer of the deposit for a viewer-ergonomics gain. Instead, the
> revision makes the structure explicit for manual exploration: Table
> @tbl-variables now shows each column's logical group, and the deposit
> ships a formal data dictionary in machine-readable form. `datapackage.json`
> is a Frictionless Table Schema giving, per column, the storage type, the
> allowed values, the range, and the share of missing values measured on the
> deposited file. It is generated by the pipeline from the same declared column
> contract that the export script enforces when writing the CSV, so they
> cannot drift from the data — and the schema is executable, so a reader can
> confirm it: `frictionless validate datapackage.json`. Our build refuses to
> package an archive whose data contradicts the schema.

Implementation record: ticket 0287 (author decision 2026-07-23, layout
kept) — contract extended with `group` and allowed values in
`scripts/_deposit_variables.py`; outputs
`deliverables/_shared/tables/tab_variables.md` (group column) and, in the
Zenodo package, `datapackage.json` (ticket 0280).

Superseded by ticket 0354: the prose data dictionary (`codebook.md`) was
retired in favour of the two machine-readable descriptors, which carry the
same per-column facts and, unlike a Markdown table, are checked against the
deposited bytes. The file was never released — no published artifact changes.
