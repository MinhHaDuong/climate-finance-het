# Country narratives

Reviewed introductory narratives are available for ZAF, IDN, VNM and SEN.
The MVP renders these alongside source-linked registry data. Their front matter
records editorial review by the coding agent, not author ratification of pilot data.

Use the ISO3 country ID as the filename. Country totals and project lists are
generated from the selected snapshot. Start future narratives from the
[country template](../templates/country.md).
