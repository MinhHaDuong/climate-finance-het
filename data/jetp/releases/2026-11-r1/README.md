# JETP Observatory 2026-11-r1 — evidence-depth revision

`jetp-observatory-2026-11-r1.zip` is a new immutable, offline edition. It
preserves the 2026-11 release and makes the distinct evidence layers visible on
the edition-history page:

- 383 named canonical portfolio identities;
- 301 frozen documentary sources;
- 3 reviewed canonical assertions, each non-aggregate; and
- 1,740 staged atomic research observations, including 279 Viet Nam RMP
  positions.

The last layer is an analytical staging count, not a common portfolio total,
payment account, reconciliation result, or canonical fact. The comparative
snapshot and raw source documents are not included in the archive.

The package is prepared locally, not deposited or hosted. It restores without
Git, DVC, a database, or network access.
