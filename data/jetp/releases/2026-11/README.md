# JETP observatory 2026-11 — reviewed-evidence extension

`jetp-observatory-2026-11.zip` is an immutable, offline MVP edition. It adds a
separate reviewed-evidence route with source hashes and locators for three
already canonical national positions. Each is a non-aggregate record: it is
neither a payment total nor a cross-country estimate.

The four-country coverage table remains present. Viet Nam has no separately
releasable reviewed-evidence row in this edition because the available headline
source has no retained source-byte hash. That is a provenance gap, not an
assertion that no activity or finance exists.

The 0822 comparative snapshot is derived/staged research material. It is not
included in this archive, is labelled `not_deployed` by the reviewed-evidence
payload, and creates no canonical observation in this edition.

The package is **prepared**, not externally deposited or hosted. It excludes raw
source documents and restores without Git, DVC, a database, or network access.
